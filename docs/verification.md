# 검증 기록

작성일: 2026-10-25, 한국 시간.

## 공개 저장소 버전

`npm test`의 배포 없는 빌드와 30개 테스트가 통과했습니다.

- 수집 9개: 작성자 구분, 답글·날짜, 표본 반환, 403·429, 점검 HTML, 필수 필드 누락, HTTPS 설정, 연결 실패
- Discord 21개: 요청 서명과 본문 보존, 잘못된 입력과 실행 대상, 지연 응답, Queue 연결, 같은 원본 메시지 수정, 만료·재시도

테스트의 서명 키, interaction token, API 응답, HTML은 합성 데이터입니다. 실제 API 성공이나 분류 정확도를 이 테스트 개수로 설명하지 않습니다.

공개 예제 설정으로 실제 계정에 배포하지 않았습니다. 개인별 Worker·D1·Queue·Discord 설정이 필요합니다.

## 이관 전 프로토타입의 실제 실행

별도 비공개 검증 환경에서 다음을 확인했습니다.

| 항목 | 결과 |
| --- | --- |
| 실제 무료 Worker에서 저장 HTML 40개 파싱 | CPU 5·5·5·6ms |
| 공개 미러에서 두 페이지 수집·파싱 | 대상 글·답글 40개, CPU 7ms |
| Queue 재시도 | 같은 합성 메시지의 1회차 재시도, 2회차 ack |
| Cron | 실제 실행 로그 확인 후 예약 목록 해제 |
| D1 | Worker 바인딩과 SELECT 확인 |
| Discord | 서버 설치와 실제 서명 확인 PING 통과, 위조 요청 401 |
| Gemini | 실제 Cloudflare 호출 성공, 한 표본에서 총 200토큰 사용 |

이 수치는 이관 전 코드와 소수 샘플의 결과입니다. 공개 저장소의 새 파일 구성으로 실제 계정에 재배포한 성능 측정이나 전체 부하 검증을 대신하지 않습니다.

무효 응답 토큰으로 수행한 거부 경로 시험을 정상 메시지 전송 성공으로 계산하지 않았습니다.

## 공개 저장소 코드의 실제 배포와 명령 등록

공개 저장소의 코드를 개인별 비공개 설정으로 기존 무료 Worker에 배포했습니다. Queue 생산자·소비자와 D1 연결을 유지했으며, 예약 실행 목록은 비어 있습니다.

| 항목 | 결과 |
| --- | --- |
| Worker 배포 | 업로드와 트리거 배포 완료 |
| 상태 확인 | `/health` HTTP 200, 검증 모드와 명령 이름 확인 |
| Discord 앱 인증 | 발급 토큰의 앱 ID 일치, HTTP 200 |
| 응답 주소 | 앱의 Interactions Endpoint URL과 배포 주소 일치 |
| `/검증` 등록 | 대상 서버에 HTTP 201, 재조회 HTTP 200 |
| 테스트 채널 | 대상 채널과 서버 ID 일치, 채팅 채널 확인 |
| 잘못된 요청 | 서명 없는 `/discord` 요청 HTTP 401 |

실제 Discord 클라이언트에서 명령을 실행하고 정상 후속 응답을 받는 확인은 아직 남아 있습니다. 명령 등록 성공만으로 수집·Gemini·응답의 전체 경로가 성공했다고 판단하지 않습니다.

## 수집 완전성

미러는 한때 HTTP 429를 반환한 뒤 정상 응답으로 복구됐습니다. 현재 접근 가능하더라도 상시 가용성을 보장할 수 없습니다.

외부 초기화 피드를 저장 표본 20개와 비교했을 때 10개만 포함됐습니다. 해당 피드도 전체 글 수집원의 대체재로 확정하지 않았습니다.

개인 화면, 실제 계정·리소스 ID, 수집 원본, 비밀 설정과 기존 로컬 이력은 이 저장소에 포함하지 않았습니다.
